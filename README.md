# 🧋 Winter Hot Chocolates — EPOS Application

A fully functional Electronic Point of Sale (EPOS) system built 
in C# using Windows Forms, developed as part of MS806 Business 
Application Programming at University of Galway.

## Features
- Product inventory with 5 size variants and dynamic pricing
- Add/remove items to cart with real-time stock deduction
- Loyalty points system (1 point per €5 spent)
- Checkout with transaction confirmation and file saving
- Sales Report and Stock Report with low-stock alerts
- Search transactions by ID or date

## Technologies
- C# / .NET Windows Forms (Visual Studio)
- File I/O for persistent stock and transaction storage
- Arrays and Lists for data structures
